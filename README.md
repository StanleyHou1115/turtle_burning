# 六六龜龜 · 燒烏龜祈晴

一個純前端的互動式「燒烏龜祈晴」網頁，讓你不必真的畫紙、燒紙，也能完成這場可愛又虔誠的儀式。

開啟 `index.html` 即可使用，無需任何安裝或伺服器。

---

## 燒烏龜由來

「燒烏龜」一說最早可追溯至 1988 年，報導提及張學友每次開演唱會前，均會以紙摺烏龜後焚燒來祈晴。新聞一出，「摺大量紙烏龜再燒掉」遂成為眾家明星趕雨神的法寶。

儀式源自演藝圈，而後被許多學生活動、婚紗業者採用。2011 年「燒烏龜守則」首次出現於婚禮論壇，不只出現「燒烏龜」諧音為「烏雲歸去」的說明，做法也由難度較高的「摺烏龜」演變成「畫烏龜」——這也是目前流傳最廣的版本。

> 參考資料：[How Dine 報導](https://www.how-dine.com.tw/news/pray-to-turtle)

## 開發動機

- **環保**：以可重複使用的網頁取代紙張，減少浪費。
- **方便**：不必畫 66 隻烏龜，一鍵完成，隨時重來。
- **趣味**：保留儀式感，加入動畫、音效與互動元素，讓祈晴更有樂趣。

---

## 功能特色

- **自動生成 66 隻烏龜**：每次開啟或重置，都會重新排列、面朝太陽，殼上還印著「好天氣」「天晴」「放晴」等吉祥字。
- **太陽與烏雲互動**：初始太陽被烏雲遮蔽，隨著儀式啟動，烏雲退散、太陽綻放金光。
- **寫實燃燒動畫**：從紙張左下方向右上方延燒，有火焰、餘燼、煙霧，最後化為灰燼堆。
- **可填寫祈願資訊**：日期、地點、天氣、活動——讓每次祈晴都有故事。
- **一鍵重來**：隨時重啟儀式，回到烏雲密佈、烏龜滿紙的初始畫面。

---

## 使用方式

1. 直接用瀏覽器打開 `index.html`。
2. 在右上方填入你的「日期、地點、天氣、活動」。
3. 點擊對應按鈕執行儀式：
   - 🔥 **燒烏龜祈晴**：同時觸發紙張燃燒與烏雲退散，太陽亮起。
   - ☁️ **烏雲退散**：單獨重播烏雲聚散動畫。
   - ↻ **重新來過**：重置全部狀態。

---

## 技術

- 純 HTML / CSS / JavaScript，單一檔案即可運行
- 烏龜以 SVG 動態產生，角度依座標計算自動朝向太陽
- 燃燒效果使用 Canvas + Perlin-like noise 生成不規則燒紙邊緣、火焰與餘燼粒子
- 烏雲退散以 CSS keyframes + `filter: blur()` 實現擴散消散
