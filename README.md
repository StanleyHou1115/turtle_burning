### 燒烏龜由來
燒烏龜一說，最早可追溯至 1988 年，報導提及張學友每次開演唱會前，均會以紙摺烏龜後焚燒來祈晴，新聞一出，「摺大量紙烏龜再燒掉」遂成為眾家明星趕雨神的法寶！
燒烏龜儀式源自演藝圈，而後被許多學生活動、婚紗業者採用，2011 年「燒烏龜守則」首次出現於婚禮論壇，不只出現燒烏龜諧音為「烏雲歸去」的說明，做法也由難度較高的「摺烏龜」變成「畫烏龜」，這也是目前流傳最廣的版本。
